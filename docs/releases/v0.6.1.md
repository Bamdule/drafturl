# v0.6.1 릴리즈 노트

> 릴리즈일: 2026-03-31
> 타입: Patch — SEO 개선

---

## 요약

홈페이지 SEO를 개선합니다. 정적 텍스트 콘텐츠를 Server Component로 분리하여 Google 크롤러 인식률을 높이고, OG 이미지와 구조화 데이터 스키마를 추가하여 검색 결과 노출 품질을 향상합니다.

---

## 변경사항

### 정적 콘텐츠 Server Component 분리
- `HomeStaticSections.tsx` (Server Component) 신규 생성
- Feature Cards, How-to-Use Steps, FAQ 섹션, Footer를 클라이언트 번들에서 분리
- Google 크롤러가 JS 실행 없이 페이지 텍스트를 직접 읽을 수 있게 됨
- `HomePage.tsx`는 인터랙티브 에디터 영역만 유지 (`"use client"`)

### FAQ 섹션 추가
- 홈페이지 하단에 FAQ 6개 항목 추가 (영어/한국어)
- "DraftURL이란?", "회원가입 필요?", "지원 형식?", "보관 기간?", "수정 가능?", "무료?" 등

### OG 이미지 추가
- `/en/opengraph-image.tsx`, `/ko/opengraph-image.tsx` 생성
- 카카오톡, 슬랙, 트위터 등 소셜 공유 시 브랜드 미리보기 이미지 표시
- 1200×630 Next.js ImageResponse 기반

### 구조화 데이터 스키마 추가
- **FAQPage 스키마**: Google 검색 결과에서 FAQ 리치 스니펫 표시 가능
- **HowTo 스키마**: 3단계 사용법 구조화 데이터
- `/en`, `/ko` 페이지에 각각 삽입

### favicon 수정
- `src/app/favicon.ico` (Next.js 기본 삼각형 아이콘) 삭제
- `public/favicon.svg` (보라 그라데이션 D 로고)가 정상 적용됨
- 검색 결과 파비콘이 브랜드 아이콘으로 표시됨
