# v0.8.0 — 가이드 페이지 추가 (MCP 연결 방법)

> 배포일: 2026-04-01

## 요약

사용 방법 가이드 허브와 MCP 연결 가이드 페이지를 추가했습니다. 헤더에 "가이드" 링크가 추가되어 모든 사용자가 접근할 수 있습니다.

## 변경 내역

### Added
- **가이드 허브 (`/guide`)** — 카드 형태의 가이드 목록 페이지
- **MCP 연결 가이드 (`/guide/mcp`)** — Claude Desktop, Claude Code, Cursor별 연결 방법, 5개 도구 설명, OAuth2 인증 안내
- **헤더 "가이드" 링크** — 로그인 여부 무관, 데스크톱/모바일 네비게이션 모두 포함
- **가이드 콘텐츠 관리** — `docs/guide/` 디렉토리에 HTML 파일로 관리, 한/영 다국어 지원

## 변경 파일

- `docs/guide/mcp.ko.html`, `mcp.en.html` — MCP 가이드 콘텐츠
- `frontend/src/lib/guide/renderGuide.ts` — HTML 파일 렌더링 유틸리티
- `frontend/src/app/guide/page.tsx` — 가이드 허브 페이지
- `frontend/src/app/guide/mcp/page.tsx` — MCP 가이드 상세 페이지
- `frontend/src/app/guide/guide.css` — 가이드 스타일시트
- `frontend/src/components/layout/Header.tsx` — "가이드" 링크 추가
- `frontend/src/dictionaries/en.json`, `ko.json` — header.guide 텍스트
- `frontend/Dockerfile.dev` — docs/guide/ 복사 추가
