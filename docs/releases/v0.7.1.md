# v0.7.1 — 랜딩페이지 UI/UX 개선

> 배포일: 2026-03-31

## 요약

랜딩페이지의 시각적 완성도와 전환율을 개선했습니다. Hero CTA 버튼, 드래그앤드롭 배너, Feature 아이콘, 하단 CTA 섹션을 추가했습니다.

## 변경 내역

### Added
- **Hero CTA 버튼** — "바로 시작하기" 버튼으로 에디터 영역까지 스크롤 유도
- **드래그앤드롭 배너** — 에디터 탭 위에 미니멀 인라인 배너로 파일 드롭 기능 시각적 안내
- **Features 아이콘** — 4개 Feature 카드에 Lucide 스타일 SVG 아이콘 추가 (Zap, Eye, Link, Sparkles)
- **하단 CTA 섹션** — FAQ 아래 "지금 바로 공유해보세요" 마무리 행동 유도 영역

## 변경 파일

- `frontend/src/components/home/HomePage.tsx` — Hero CTA, 드롭 배너, editor 앵커
- `frontend/src/components/home/HomeStaticSections.tsx` — Feature 아이콘, 하단 CTA 섹션
- `frontend/src/dictionaries/en.json` — 영어 텍스트 추가
- `frontend/src/dictionaries/ko.json` — 한국어 텍스트 추가

## 기술 노트

- Feature 아이콘은 인라인 SVG로 구현 (Server Component 호환, 외부 의존성 없음)
- 하단 CTA `<a href="#editor">`는 `scroll-mt-4`로 자연스러운 스크롤 위치 보정
- 드롭 배너는 기존 `FileDropZone`의 document 레벨 드래그 리스너와 독립적으로 작동 (시각적 힌트 역할만)
