# Release v0.4.0 — 회원탈퇴 & 문서 생성 제한

> 배포일: 2026-03-30
> 환경: Galaxy Book 3 Pro (Ubuntu 24.04) + Cloudflare Tunnel + Self-hosted Runner
> URL: https://drafturl.com

---

## 개요

회원탈퇴(Hard Delete) 기능과 문서 생성 제한(30개) 서버 사이드 강화를 구현한 릴리즈. 내 정보 페이지를 신설하여 계정 관리 기반을 마련함.

---

## 주요 변경사항

### 회원탈퇴 (Hard Delete)
- `DELETE /api/v1/auth/me` 엔드포인트 추가
- FK cascade 활용: 유저 삭제 시 storage_usage, refresh_tokens 자동 삭제, 문서는 user_id=NULL로 전환 후 고아 문서 스케줄러가 비동기 정리
- DB 마이그레이션 없이 기존 FK 설계 활용

### 문서 생성 제한 강화
- 백엔드에서 Free 플랜 30개 문서 제한을 서버 사이드에서 강제
- `DOCUMENT_LIMIT_EXCEEDED` (403) 에러코드 반환
- 프론트엔드에서 해당 에러코드에 대한 사용자 친화적 메시지 표시

### 내 정보 페이지 (/account)
- 계정 정보(이름, 이메일, 플랜) 표시
- 회원탈퇴는 Danger Zone에 배치
- Header 아바타 클릭 시 내 정보 페이지로 이동

| 영역 | 변경 내용 |
|------|-----------|
