## 신규 기능

### 공유 전 태그/비밀번호 설정

홈 화면에서 공유 버튼을 누르기 전에 태그와 비밀번호를 미리 설정할 수 있습니다.

- 로그인 사용자에게 파일 로드 후 태그/비밀번호 옵션 섹션 표시
- 기존 태그 선택 + 새 태그 생성 (Enter로 추가, `×`로 제거)
- 새 태그는 공유 버튼 클릭 시점에 생성 → 공유 안 하면 고아 태그 미생성
- 비밀번호 설정 (토글 입력)
- PublishResultModal 단순화 (URL 표시 전용)

### 문서 미리보기 (Preview)

내 문서 리스트에서 각 문서의 내용을 첫 120자 미리 볼 수 있습니다.

- 신규 생성/수정 문서에 자동 추출·저장
- HTML: 태그 제거 후 텍스트 추출
- Markdown: 마크다운 문법 제거 후 텍스트 추출
- DB 컬럼 저장 방식 (R2 재조회 없음)

### 문서 목록 정렬

내 문서 대시보드에서 정렬 기준을 변경할 수 있습니다.

- 최신순 (기본)
- 제목순 (오름차순)
- 크기순 (내림차순)

## UX 개선

### 내 문서 대시보드
- **태그 필터**: 연결 문서가 없는 태그 자동 숨김
- **검색창**: 검색어 입력 시 `×` 초기화 버튼 표시
- **검색 빈 상태**: "문서 없음" vs "검색 결과 없음" 메시지 분리
- **커스텀 정렬 드롭다운**: 시스템 `<select>` → 디자인 시스템 통일 드롭다운
- **compact 카드**: 미리보기·태그 없는 카드는 세로 padding 축소
- **hover accent**: 카드 hover 시 왼쪽 보라색 accent border
- **자동 생성 제목**: italic + muted 스타일로 사용자 지정 제목과 구분
- **전체 글씨 밝기**: secondary/muted 색상 전반 상향 조정

### 태그 생명주기
- 태그에서 마지막 문서 연결 해제 시 태그 자동 삭제
- 문서 삭제 시 연결 태그 중 ACTIVE 문서 없는 태그 자동 삭제

## 버그 수정

### 내 문서 제목 검색 안 됨
- **원인**: macOS 파일명이 NFD(자모 분해형) 유니코드로 저장되고, 검색 입력은 NFC(합성형)로 전달되어 LIKE 매칭 실패
- **수정**: 
  - 검색 파라미터 NFC 정규화 (Java `Normalizer.normalize`)
  - 신규 문서 저장 시 제목 NFC 정규화
  - V9 마이그레이션: 기존 NFD 저장 제목 일괄 NFC 변환

### 제목 없는 문서 검색 제외
- **원인**: JPQL `LOWER(d.title) LIKE ...` — title이 null이면 전체 표현식이 null(false)
- **수정**: `LOWER(COALESCE(d.title, '')) LIKE ...`
- V8 마이그레이션: 기존 null 제목을 날짜 기반 제목으로 일괄 설정
