## 버그 수정

### 한글 태그 입력 중 Enter 이중 발화 방지

한국어 입력 시 IME 조합 확정(Enter) → 태그 생성(Enter)이 연속으로 발화되어 빈 태그가 중복 생성되던 문제를 수정했습니다.

**원인**: `onKeyDown` 핸들러에서 `e.nativeEvent.isComposing` 체크 누락.
한글 조합 중 Enter로 글자를 확정할 때 `isComposing: true`인 keydown 이벤트가 먼저 발생하며, 이를 무시하지 않으면 태그 생성이 중복 트리거됩니다.

**수정 내용**:

```ts
// Before
if (e.key === "Enter") { handleCreateTag(); }

// After
if (e.key === "Enter" && !e.nativeEvent.isComposing) { handleCreateTag(); }
```

**영향 범위**:
- `HomePage` — 공유 전 새 태그 생성 입력창
- `TagPicker` — 대시보드 문서 카드의 태그 관리 드롭다운
