# Release v0.1.0 — MVP

> 배포일: 2026-03-27
> 환경: Galaxy Book 3 Pro (Ubuntu 24.04) + Cloudflare Tunnel
> URL: https://drafturl.com

---

## 개요

DraftURL MVP 첫 배포. "붙여넣기 → URL 생성 → 공유" 핵심 루프를 검증하기 위한 최소 기능 세트.

---

## 주요 기능

### 문서 배포
- HTML/Markdown 텍스트 붙여넣기 즉시 배포
- nanoid 8자리 slug 기반 고유 URL 발급 (`drafturl.com/{slug}`)
- 실시간 미리보기 (Monaco Editor + iframe)
- Markdown → 스타일링된 HTML 자동 렌더링

### 인증
- Google / GitHub OAuth2 소셜 로그인
- httpOnly 쿠키 기반 JWT 인증 (BFF 프록시 패턴)
- 토큰 자동 갱신

### 문서 관리
- 대시보드에서 내 문서 목록 조회
- 문서 수정 및 재배포 (동일 URL 유지)
- 문서 삭제

### 만료 정책
- 비로그인: 24시간 후 자동 만료
- 로그인(Free): 영구 보관

---

## 아키텍처

- **Backend**: Port-Adapter + UseCase 패턴
- **Frontend**: httpOnly 쿠키 BFF 프록시 패턴 (Next.js API Route → Backend)
- **문서 서빙**: R2 CDN 직접 서빙 방식
- **배포**: Docker Compose 6 컨테이너 구성, Cloudflare Tunnel 외부 노출
