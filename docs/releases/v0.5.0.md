# v0.5.0 릴리즈 노트

> 릴리즈일: 2026-03-30

## 요약

국내외 서비스를 위한 법적 약관 페이지 추가. 이용약관, 개인정보처리방침, 이용제한정책을 한국어/영어로 제공하고, 서비스 내 4곳에 약관 링크를 노출합니다.

## 새 기능

### 약관 페이지 (3개)

| 경로 | 내용 |
|------|------|
| `/terms` | 이용약관 (Terms of Service) |
| `/privacy` | 개인정보처리방침 (Privacy Policy) |
| `/aup` | 이용제한정책 (Acceptable Use Policy) |

- `docs/legal/` 디렉토리의 Markdown 파일을 빌드 타임에 렌더링
- 한국어/영어 다국어 지원 (locale에 따라 자동 전환)
- 영어 페이지 상단에 "한국어 원본이 법적 효력을 가집니다" 번역 고지

### 약관 노출 위치 (4곳)

1. **홈페이지 Footer** — 이용약관, 개인정보처리방침 링크
2. **회원가입 페이지** — "계속 진행하면 이용약관 & 개인정보처리방침에 동의하게 됩니다"
3. **로그인 페이지** — 동일
4. **비회원 문서 생성** — "공유 시 이용약관에 동의합니다"

## 약관 내용 요약

- **이용약관**: 서비스 정의, 회원/비회원 구분, 문서 만료 정책(비회원 24h/회원 영구), 5MB 제한, 30개 문서 한도, HTML 새니타이징 고지, 면책
- **개인정보처리방침**: 이메일/이름/비밀번호 수집, Umami 분석, 쿠키(JWT), Cloudflare R2/Sentry 위탁, 이용자 권리
- **이용제한정책**: 피싱/악성코드/CSAM 금지, 저작권 침해 신고, 단계별 제재

## 기술 변경

- `frontend/src/lib/legal/renderMarkdown.ts` — unified/remark/rehype 기반 Markdown→HTML 렌더러
- 3개 Server Component 페이지 추가 (Next.js App Router)
- 사전(dictionaries) 키 추가: `publish.termsAgreement`, `publish.termsLink`, `publish.termsAgreementSuffix`
