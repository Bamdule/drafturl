# Release v0.9.0 — 랜딩페이지 리디자인 + 탈퇴 로그 + 이메일 알림

> 배포일: 2026-04-01
> 환경: Galaxy Book 3 Pro (Ubuntu 24.04) + Cloudflare Tunnel + Self-hosted Runner
> URL: https://drafturl.com

---

## 개요

랜딩페이지를 2컬럼 드롭존 기반으로 전면 리디자인. 탈퇴 로그, Resend 이메일 알림, 스케줄러 최적화를 포함한 릴리즈.

---

## 주요 변경사항

### 랜딩페이지 리디자인
- 기존 Monaco Editor + 미리보기 패널 → 2컬럼 (히어로+3스텝 | 드롭존) 구조
- 드롭존: 파일 드래그앤드롭, Ctrl+V 붙여넣기, 클릭 파일 선택
- 파일 등록 후: 드롭존 내부에 파일 정보 + 미리보기/공유 버튼 표시
- 모바일 반응형: 1컬럼, 드롭존 높이 축소, 버튼 세로 배치

### 가이드 페이지 확장
- HomeStaticSections의 Features/Steps/FAQ → 가이드 페이지로 이동
- 가이드 목록(MCP 연결)을 최상단 배치
- 시작하기/주요기능/FAQ 섹션 재구성

### 탈퇴 로그
- V6 마이그레이션: withdrawal_logs 테이블
- 탈퇴 시 이메일 SHA-256 해시 + 타임스탬프 기록

### Resend 이메일 알림
- 문의 접수 시 관리자 Gmail로 알림 이메일 발송
- API 키 미설정 시 skip (로컬 개발 호환)

### 스케줄러 최적화
- 회원탈퇴 시 ACTIVE 문서에 1시간 만료 부여 → 기존 배치가 자연스럽게 정리
- PendingCleanupScheduler 주기 5분 → 1시간
