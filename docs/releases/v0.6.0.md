# v0.6.0 릴리즈 노트

**릴리즈일:** 2026-03-30

## 요약

HTML sanitizer 보안 강화 릴리즈. 피싱, 악성 리다이렉트, 데이터 유출을 다층 방어 체계로 방지한다.

## 주요 변경사항

### 보안 강화

**CSP(Content Security Policy) 자동 주입**
- 모든 HTML 문서의 `<head>`에 `connect-src 'none'` CSP meta 태그를 자동 삽입
- `fetch()`, `XMLHttpRequest`, `WebSocket`, `EventSource` 등 네트워크 요청 차단
- 공격자가 자체 CSP를 삽입해도 교집합 정책으로 완화 불가

**피싱 탐지 및 차단**
- 유명 브랜드(네이버, 구글, 카카오, 페이스북 등 30개) 사칭 + password input 조합 감지
- 업로드 시점에 `MaliciousContentException` (400 BAD_REQUEST)으로 거부
- 브랜드명만 있거나 password input만 있는 경우는 허용

**악성 리다이렉트 차단**
- `<meta http-equiv="refresh">` 외부 URL 리다이렉트 감지 및 차단
- `window.location`, `document.location`, `top.location` JS 리다이렉트 감지 및 차단
- 상대 경로, 내부 URL 리다이렉트는 허용

**password input 무력화**
- `type="password"` → `type="text"` 자동 변환
- 마스킹(●●●●) 제거로 피싱 효과 무력화

### 정책 변경

**폼 태그 허용**
- `<form>`, `<input>`, `<select>`, `<button>` 등 폼 태그를 더 이상 제거하지 않음
- sandbox iframe이 `allow-forms` 없이 폼 제출을 브라우저 레벨에서 차단하므로 안전
- LLM 생성 HTML의 폼 UI가 정상적으로 렌더링됨

## 보안 아키텍처

```
[업로드] → ContentValidator (피싱/리다이렉트 탐지 → 차단)
       → ContentSanitizer (CSP 주입, password 변환, 위험 태그 제거)
       → [저장]

[조회]  → Sandbox iframe (allow-scripts, no allow-forms/same-origin/top-navigation)
       → CSP meta (connect-src 'none')
       → [렌더링]
```

## 영향 범위

- 백엔드: `JsoupContentSanitizer`, `JsoupContentValidator`, `CreateDocumentUseCase`, `UpdateDocumentUseCase`
- 프론트엔드: 변경 없음 (sandbox 설정 유지)
