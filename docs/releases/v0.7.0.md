# Release v0.7.0 — 1:1 문의 / 콘텐츠 신고

> 배포일: 2026-03-31
> 환경: Galaxy Book 3 Pro (Ubuntu 24.04) + Cloudflare Tunnel + Self-hosted Runner
> URL: https://drafturl.com

---

## 개요

사용자 피드백 채널 구축. 1:1 문의/버그 리포트 폼, 문서 뷰어 콘텐츠 신고 기능, 서비스 이메일(Cloudflare Email Routing) 설정을 완료한 릴리즈.

---

## 주요 변경사항

### 서비스 이메일
- Cloudflare Email Routing 설정: support@drafturl.com, abuse@drafturl.com
- Gmail 수신함(drafturl.team@gmail.com)으로 포워딩

### 문의 페이지 (/contact)
- 유형 선택 (일반 문의 / 버그 리포트), 이메일, 이름, 제목, 내용 폼
- 로그인 상태면 이메일/이름 자동 채움
- 성공 시 감사 메시지 표시

### 콘텐츠 신고
- 문서 뷰어에 신고 버튼 추가 (조용한 배치)
- 신고 Dialog: 이메일 + 사유 입력 → DB 저장

### Backend
- Inquiry 도메인: entity, enum (InquiryType, InquiryStatus), repository, usecase, controller
- POST /api/v1/inquiries (permitAll, 비로그인 가능)
- DB 마이그레이션 V5: inquiries 테이블

---

| 영역 | 변경 내용 |
