# v0.9.4 릴리즈 노트

> 배포일: 2026-04-03

## 요약

랜딩 페이지 UX 개선 — Ctrl+V 붙여넣기 기능 실제 구현 및 레이아웃 버그 수정.

---

## 신기능

### Ctrl+V 전체 페이지 붙여넣기

기존에는 드롭존에 "Ctrl+V로 붙여넣기" 힌트 문구만 있었고 실제 동작은 하지 않았습니다.

**구현**: `FileDropZone.tsx`에 `paste` 이벤트 핸들러 추가
- INPUT/TEXTAREA에 포커스가 있을 때는 동작하지 않음 (기존 입력 보호)
- `<!DOCTYPE`, `<html>` 등의 패턴으로 HTML/Markdown 자동 감지
- 성공 시 토스트 알림 표시

---

## 버그 수정

### button-in-button HTML 구조 오류

파일 미선택 상태의 드롭존 `<div>`에 `role="button"` + `tabIndex`가 설정된 상태에서 내부에 `<button>파일 선택하기</button>`가 중첩되어 있었습니다.
이는 ARIA 명세 위반이며 브라우저 접근성 경고를 유발합니다.

**수정**: 외부 div에서 `role="button"`, `onClick`, `tabIndex`, `onKeyDown` 제거 — 드래그 타겟 역할만 유지

### 수직 레이아웃 중앙 정렬

그리드 컨테이너가 페이지 상단에 치우쳐 보이는 문제가 있었습니다.

**수정**: 그리드를 `flex flex-1 items-center py-8` 래퍼로 감싸 수직 중앙 정렬

### use case 태그 / 만료 안내 모바일 미노출

use case 태그 섹션과 만료 안내 문구에 `hidden md:*` 클래스가 적용되어 모바일에서 보이지 않았습니다.

**수정**: 두 요소 모두 모바일에서도 항상 표시되도록 변경
