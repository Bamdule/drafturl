# Release v0.2.0 — 개발 인프라 안정화 & 사용성 개선

> 배포일: 2026-03-28
> 환경: Galaxy Book 3 Pro (Ubuntu 24.04) + Cloudflare Tunnel + Self-hosted Runner
> URL: https://drafturl.com

---

## 개요

개발 인프라 자동화, 사용성 개선, 모바일 대응, SEO 기본 설정을 완료한 릴리즈.

---

## 주요 변경사항

### 1. 개발서버 CI/CD 파이프라인

- GitHub Actions Self-hosted Runner 기반 자동 배포
- main 브랜치 push 시 빌드 → Docker Compose 배포 → 헬스체크 자동 수행
- CI 워크플로 (백엔드 빌드 + 프론트엔드 빌드/린트) 분리 운영
- 수동 배포 트리거(workflow_dispatch) 지원
- GitHub Secrets(dev 환경)로 크레덴셜 관리

### 2. 사용성 개선

- 메인 페이지 데모 데이터 미리보기만 허용, 공유 버튼 비활성화
- 삭제 모달 버튼 색상 개선
- 서비스 아이콘 커스텀 교체
- 서비스 소개 및 사용 가이드 추가
- 문서 기본 제목: "제목 없음" → `YYYY-MM-DD HH:mm 문서` 형식
- 만료/삭제 문서 전용 에러 페이지

### 3. 모바일 대응

- 홈페이지 및 대시보드 모바일 레이아웃 지원
- 모바일 핀치 줌(확대/축소) 비활성화

### 4. SEO 기본 설정

- `robots.ts`: 크롤러 허용/차단 규칙 (공개 페이지만 크롤링)
- `sitemap.ts`: 홈페이지 URL 포함
- Open Graph / Twitter Card 메타태그 추가
- `metadataBase` 설정 (`NEXT_PUBLIC_SITE_URL` 환경변수)
- 보호 페이지(dashboard, auth, expired)에 `noindex` 적용

### 5. 코드 품질

- 프론트엔드 lint 에러 전량 수정 (CI 통과)
- 미사용 코드/import 정리
- deprecated token.ts 삭제
- React 19 새 lint 규칙(set-state-in-effect, error-boundaries) warning으로 조정
