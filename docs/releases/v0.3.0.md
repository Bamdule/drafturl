# Release v0.3.0 — 보안 강화 & MCP 서버 & 접근성 확대

> 배포일: 2026-03-30
> 환경: Galaxy Book 3 Pro (Ubuntu 24.04) + Cloudflare Tunnel + Self-hosted Runner
> URL: https://drafturl.com

---

## 개요

사용자 접근성 확대(소셜 로그인, 비밀번호 보호), 보안 강화(Sanitizer 피싱 방지, 보안 점검), MCP 서버 구현, SEO/모니터링 추가를 완료한 릴리즈.

---

## 주요 변경사항

### 1. 소셜 로그인 추가

- 네이버 OAuth2 연동 (백엔드 + 프론트엔드)
- 카카오 OAuth2 연동 (백엔드 + 프론트엔드)
- 기존 Google/GitHub + 네이버/카카오 총 4개 소셜 로그인 지원

### 2. 보안 강화

- **HTML Sanitizer 피싱 방지**: form/input/password/textarea/select/button 등 폼 관련 태그 12종 제거
- **문서 생성(CREATE) 경로 sanitizer 적용**: 기존에는 UPDATE만 적용되어 CREATE 시 raw HTML이 저장되던 문제 수정
- Google Search Console 피싱 경고 원인 해결
- XSS 방어, 보안 헤더, 프록시 검증, 인증 미들웨어 점검 및 수정
- iframe sandbox에서 `allow-forms`, `allow-popups-to-escape-sandbox` 제거

### 3. MCP 서버 + OAuth2 인증

- MCP 서버 엔드포인트 구현 (문서 CRUD)
- OAuth2 Authorization Code + PKCE 인증 흐름
- 프론트엔드 OAuth2 프록시 (`/oauth2/*`)
- Claude Desktop 등 AI 클라이언트에서 문서 관리 가능

### 4. 공유 문서 비밀번호 보호

- 문서 생성/수정 시 비밀번호 설정 옵션
- 비밀번호 보호 문서 접근 시 입력 화면
- 비밀번호 bcrypt 해싱 저장

### 5. SEO 강화

- 다국어 라우팅 (i18n): `/ko`, `/en` 경로 분리
- Google Search Console 등록 + 소유권 확인 메타태그

### 6. 모니터링

- Umami 트래킹 스크립트 + 커스텀 이벤트 추적
- Uptime Kuma 서비스 모니터링 구성

### 7. UI/UX 개선

- 전체 UI/UX 개선 (로그인/회원가입/홈/404/대시보드)

### 8. 테스트 & 코드 품질

- 백엔드 단위 테스트 101개 (UseCase 6개, Sanitizer 피싱 방지 5개, SlugGenerator, JwtProvider 등)
- VERSION 파일 기반 버전 관리 체계 도입
