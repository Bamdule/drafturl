## 신규 기능

### 게스트 문서 이관

비로그인 사용자가 문서를 만든 뒤 로그인하면, 해당 문서가 자동으로 내 계정에 영구 보관됩니다.

**흐름:**
1. 비로그인 상태로 문서 생성
2. PublishResultModal에서 "로그인하면 영구 보관" 클릭
3. 로그인 완료
4. 대시보드에서 문서 영구 보관 확인

**백엔드**: `POST /api/v1/documents/{slug}/claim`
- 인증 필수
- 소유자 없는(userId=null) ACTIVE 문서만 이관 가능
- 이관 성공 시 expiresAt 제거 (영구 보관), StorageUsage 반영
