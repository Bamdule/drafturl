## 1. 서비스 정체성 요약

| 키워드 | 설명 |
|--------|------|
| **LLM/AI 생성 콘텐츠** | Claude, ChatGPT 등이 만든 HTML/MD 문서가 주 대상 |
| **즉시 공유** | 붙여넣기 또는 업로드 -> 즉시 URL 생성 (극단적 단순함) |

| **글로벌 타겟** | LLM 사용자 (개발자, 기획자, 팀) -- 영어권 포함 |

서비스명이 담아야 할 핵심 연상: **"AI가 만든 것 -> 바로 공유"**

## 4. 최종 후보 (검증 통과)

### 4.1 Promptpage

| 항목 | 내용 |
|------|------|
| 발음 | PROMPT-page (2음절+1음절, 3음절) |
| 의미 | "프롬프트로 만든 페이지" - LLM/AI 정체성 직접 표현 |
| 글자 수 | 10자 |
| 검증 결과 | promptpage.com/.io 직접적인 서비스 없음. prompt.io는 별도 서비스(정치 문자 플랫폼). "Promptpage"라는 이름의 앱/서비스는 검색에서 발견되지 않음 |

**장점**
- LLM 사용자가 즉시 이해할 수 있는 이름 ("프롬프트 -> 페이지")
- AI/LLM 생태계와의 연결성이 가장 강함
- 향후 "살아있는 문서 플랫폼"으로 확장 시에도 자연스러움

**단점**
- 3음절로 약간 길다
- "Prompt"가 AI 버블과 함께 유행어가 될 수 있음 (시대에 묶임)
- 줄임말(PP)이 직관적이지 않음

**종합 점수: 8.5/10**

### 4.2 Sharegen

| 항목 | 내용 |
|------|------|
| 발음 | SHARE-gen (2음절) |
| 의미 | "Share" + "Gen(erated)" - AI 생성물 공유 |
| 글자 수 | 8자 |
| 검증 결과 | Go 언어의 keyshare 라이브러리에 sharegen이라는 CLI 도구가 있으나, 이는 암호화 관련 개발 도구이며 웹 서비스/상업 제품이 아님. sharegen.com/.io/.dev 도메인에 활성 서비스 없음 |

**장점**
- 2음절로 짧고 기억하기 쉬움
- "공유" + "생성"이라는 핵심 가치를 직접 전달
- 발음이 명확하고 글로벌하게 통함

**단점**
- Go 라이브러리 도구와 이름 충돌 (영향은 미미)
- "Gen"이 다소 일반적
- 축약어 느낌이 날 수 있음

**종합 점수: 8.0/10**

### 4.3 Tossdoc

| 항목 | 내용 |
|------|------|
| 발음 | TOSS-doc (2음절) |
| 의미 | "Toss" (던지다) + "Doc" (문서) - 문서를 가볍게 던지듯 공유 |
| 글자 수 | 7자 |
| 검증 결과 | "Tossdoc"이라는 이름의 앱/서비스/제품이 검색에서 발견되지 않음. "Toss"는 한국 금융 앱으로 유명하지만 "Tossdoc"은 별도 제품 없음 |

**장점**
- 2음절로 짧고 경쾌함
- "던지다"라는 동작이 "즉시 공유"의 캐주얼함을 잘 표현
- 기억하기 매우 쉬움
- 한국 사용자에게 "Toss" 브랜드의 친숙함이 긍정적 연상 가능

**단점**
- 한국에서 Toss(토스) 금융 앱과 혼동 가능 (한국 시장 한정)
- AI/LLM 정체성이 이름에 직접 드러나지 않음
- "Toss"가 "버리다"라는 부정적 뉘앙스를 줄 수 있음

**종합 점수: 7.5/10**

**단점**
- "URL"이 기술적으로 느껴질 수 있음
- 3음절
- 일반 사용자에게 "Draft"가 미완성이라는 인상을 줄 수 있음

**종합 점수: 7.0/10**

|------|------|

- AI/LLM 정체성이 이름에 직접 드러나지 않음

## 6. 최종 추천

### 1순위: Promptpage

LLM 문서 공유 서비스의 정체성을 가장 직관적으로 전달합니다. "프롬프트로 만든 것을 페이지로 공유한다"는 메시지가 이름 자체에 담겨 있습니다. AI/LLM 사용자라면 이름만 듣고 서비스를 이해할 수 있습니다.

단, 3음절이라는 점과 "Prompt"가 시대적 유행어에 묶일 수 있다는 리스크가 있습니다.

### 2순위: Sharegen

더 짧고 범용적인 이름을 원한다면 Sharegen을 추천합니다. 2음절이며, "Share + Generated"의 의미가 AI 생성 콘텐츠 공유라는 본질을 잘 담고 있습니다. 향후 "AI 생성물 공유 플랫폼"이라는 더 넓은 비전으로 확장하기에도 좋습니다.

### 3순위: Tossdoc

가장 기억하기 쉽고 캐주얼한 이름입니다. "문서를 가볍게 던져서 공유한다"는 UX의 핵심 경험을 잘 포착합니다. 다만 한국 시장에서 "Toss" 금융 앱과의 연상에 주의가 필요합니다.

### 4. 누락된 고려사항

**상표권 (Trademark)**

원문 섹션 8(다음 단계)에서 USPTO/KIPRIS 상표 검색을 언급했으나, 이는 사후 단계로 미루어져 있습니다. 그러나 상표 검색은 도메인 가용성보다 더 중요한 선행 조건입니다. 특히:
- "Prompt"를 포함한 이름은 AI 분야에서 기술 서술어(descriptive term)로 분류될 가능성이 있어 상표 등록 거절 위험이 있습니다.
- Tossdoc은 Viva Republica의 "Toss" 상표와 유사성으로 인해 분쟁 리스크가 실질적입니다.

**소셜 미디어 핸들 가용성**

도메인 가용성은 검토되었으나, @promptpage, @sharegen, @tossdoc 등 주요 소셜 미디어(X/Twitter, Instagram, LinkedIn, GitHub) 핸들 가용성은 검토되지 않았습니다. 소셜 미디어 핸들과 서비스명이 일치하지 않으면 브랜드 일관성이 떨어집니다.

**유사 서비스와의 포지셔닝 차별화**

"Prompt" 관련 서비스(PromptShare, PromptDen, PromptDrive, PromptHub)가 이미 시장에 존재하는 상황에서 "Promptpage"가 어떻게 차별화될 것인지에 대한 포지셔닝 분석이 없습니다. 이름이 유사 서비스군에 묻힐 위험이 있습니다.

**발음의 국제성 — 비영어권 언어별 구체 검토 부재**

원문은 "비영어권에서도 쉽게 발음 가능한가"를 기준으로 제시했으나, 실제로 각 이름이 일본어, 중국어, 아랍어권에서 어떻게 발음되는지 구체적 검토가 없습니다. 예:
- "Sharegen"은 일본어에서 "シェアゲン"으로 자연스럽게 발음 가능
- "Promptpage"는 "プロンプトページ"로 길어짐
- "Docfling"은 "fling" 발음이 다수 비영어권에서 어렵습니다

**App Store / Play Store 등록명 충돌**

도메인 외에 App Store/Play Store에서의 이름 등록 가능 여부가 검토되지 않았습니다. 앱 이름은 도메인과 달리 완전한 고유성이 요구되지 않지만, 검색 노출 전략에 영향을 줍니다.

#### 2순위 추천: **Promptpage**

설계 에이전트의 1순위 추천을 유지하되, 상표 리스크 선검토를 조건으로 추천합니다.

**이유:**
- LLM 사용자 타겟 시 이름만으로 서비스를 이해할 수 있는 직관성은 여전히 최고 수준입니다
- "프롬프트로 만든 것을 페이지로" 라는 내러티브가 마케팅 메시지로 즉시 활용 가능합니다

**조건부 유의사항:**
- USPTO/KIPRIS에서 "Prompt"의 서술적 용어 해당 여부를 사전 확인할 것
- PromptShare, PromptDen 등 기존 서비스들과의 브랜드 차별화 전략을 수립할 것
- 도메인 등록 전 상표 선등록 여부를 반드시 확인할 것

### 7. 요약 권고사항

1. **즉시 실행**: Sharegen과 Promptpage에 대해 USPTO(https://tmsearch.uspto.gov/) 및 KIPRIS에서 상표 선행조사를 수행하세요. 이 단계는 도메인 등록보다 반드시 먼저 해야 합니다.
2. **도메인 직접 확인**: `sharegen.com`, `sharegen.io`, `promptpage.com`, `promptpage.io`를 Namecheap/GoDaddy 등 registrar에서 직접 확인하세요. 웹 검색만으로는 도메인 실제 등록 여부를 완전히 검증할 수 없습니다.
3. **소셜 핸들 확보**: 서비스명 결정 즉시 주요 소셜 미디어 핸들(@sharegen, @promptpage)을 선점하세요.
4. **Tossdoc 재고**: Toss의 브랜드 확장 공격성과 글로벌화를 고려할 때, 법적 리스크 검토 없이 이 이름을 사용하는 것은 권장하지 않습니다.
5. **Docfling 제외 권고**: IBM Docling과의 발음 유사성 및 "fling"의 부정적 뉘앙스로 인해 실질적 사용에서 제외하는 것이 좋습니다.
