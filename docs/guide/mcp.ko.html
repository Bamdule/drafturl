MCP 연결 가이드

DraftURL은 MCP(Model Context Protocol) 서버를 제공합니다. AI 클라이언트(Claude Desktop, Claude Code, Cursor 등)에서 DraftURL에 직접 문서를 생성하고 관리할 수 있습니다.

MCP 서버 정보

항목값
서버 URLhttps://drafturl.com/mcp/transport
프로토콜Streamable HTTP
인증OAuth2 (PKCE)

클라이언트별 연결 방법

Claude Desktop

claude_desktop_config.json 파일에 다음을 추가하세요.

{
  "mcpServers": {
    "drafturl": {
      "url": "https://drafturl.com/mcp/transport"
    }
  }
}

설정 파일 위치:

  • macOS: ~/Library/Application Support/Claude/claude_desktop_config.json
  • Windows: %APPDATA%\Claude\claude_desktop_config.json

Claude Code

터미널에서 다음 명령어를 실행하세요.

claude mcp add drafturl --transport streamable-http https://drafturl.com/mcp/transport

Cursor

프로젝트 루트의 .cursor/mcp.json 파일에 다음을 추가하세요.

{
  "mcpServers": {
    "drafturl": {
      "url": "https://drafturl.com/mcp/transport"
    }
  }
}

사용 가능한 도구

도구설명인증
create_documentHTML 또는 Markdown 문서를 생성하고 공유 URL을 발급합니다.선택
get_documentslug로 문서의 내용과 메타데이터를 조회합니다.필수
update_document기존 문서의 내용, 제목, 비밀번호를 수정합니다.필수
delete_document문서를 삭제합니다.필수
list_documents내 문서 목록을 페이지네이션으로 조회합니다.필수

create_document 파라미터

파라미터필수설명
contentO문서 내용 (HTML 또는 Markdown)
typeO문서 유형: html 또는 markdown
titleX문서 제목 (최대 200자)
passwordX문서 비밀번호 (4~100자)

인증

문서 조회, 수정, 삭제, 목록 도구는 로그인이 필요합니다. MCP 클라이언트에서 처음 인증이 필요한 도구를 호출하면, OAuth2 인증 흐름이 자동으로 시작됩니다.

  1. 브라우저에서 DraftURL 로그인 페이지가 열립니다.
  2. 로그인 후 접근 권한을 승인합니다.
  3. 인증이 완료되면 MCP 클라이언트로 자동 돌아옵니다.

참고: create_document는 로그인 없이도 사용할 수 있지만, 비로그인으로 생성한 문서는 24시간 후 자동 만료됩니다.

사용 예시

Claude에게 다음과 같이 요청해보세요.

  • "이 마크다운 문서를 DraftURL에 공유해줘"
  • "내 DraftURL 문서 목록을 보여줘"
  • "이 HTML 리포트를 DraftURL에 올리고 URL을 알려줘"
