MCP Connection Guide

DraftURL provides an MCP (Model Context Protocol) server. You can create and manage documents on DraftURL directly from AI clients like Claude Desktop, Claude Code, and Cursor.

Official Registry: DraftURL MCP is registered on the MCP Registry as io.github.Bamdule/drafturl.

MCP Server Info

ItemValue
Server URLhttps://drafturl.com/mcp/transport
ProtocolStreamable HTTP
AuthenticationOAuth2 (PKCE)
InstallationNot required (remote server)

Setup by Client

Claude Code (Terminal)

The simplest way. Just run one command in your terminal.

claude mcp add --transport http drafturl https://drafturl.com/mcp/transport

This registers as a global setting. DraftURL MCP will be available in all projects.

For per-project setup, create a .mcp.json file in your project root:

{
  "mcpServers": {
    "drafturl": {
      "type": "http",
      "url": "https://drafturl.com/mcp/transport"
    }
  }
}

Note: Project-level MCP shows a trust confirmation dialog on first use.

Claude Desktop

Add the following to your claude_desktop_config.json.

{
  "mcpServers": {
    "drafturl": {
      "url": "https://drafturl.com/mcp/transport"
    }
  }
}

Config file location:

  • macOS: ~/Library/Application Support/Claude/claude_desktop_config.json
  • Windows: %APPDATA%\Claude\claude_desktop_config.json

Cursor

Add the following to .cursor/mcp.json in your project root.

{
  "mcpServers": {
    "drafturl": {
      "url": "https://drafturl.com/mcp/transport"
    }
  }
}

Authentication

The get, update, delete, and list tools require login. When you first call a tool that requires authentication, the OAuth2 flow starts automatically.

  1. A DraftURL login page opens in your browser.
  2. Log in with email/password or Google account.
  3. Approve access.
  4. Once authenticated, you're returned to the MCP client.

Note: create_document works without login, but guest documents expire after 24 hours. Log in to keep them permanently.

Available Tools

create_document — Create a document

Create an HTML or Markdown document and get a shareable URL.

ParameterRequiredDescription
contentYesDocument content (HTML or Markdown)
typeYesDocument type: html or markdown
titleNoDocument title (max 200 chars)
passwordNoPassword to protect document (4-100 chars)

Example response:

{
  "id": "ELaEXHezsupz",
  "slug": "ELaEXHezsupz",
  "url": "https://drafturl.com/ELaEXHezsupz",
  "title": "Marketing Report",
  "docType": "html",
  "status": "active"
}

get_document — Get a document

Get a document's content and metadata by slug. Only your own documents can be retrieved.

ParameterRequiredDescription
slugYesDocument identifier (last part of URL, e.g., ELaEXHezsupz)

update_document — Update a document

Update an existing document's content, title, or password. Only send the fields you want to change.

ParameterRequiredDescription
slugYesDocument identifier
contentNoNew content (HTML or Markdown)
titleNoNew title (max 200 chars)
passwordNoNew password. Send empty string ("") to remove password

delete_document — Delete a document

Delete a document. The shared URL will no longer be accessible.

ParameterRequiredDescription
slugYesDocument identifier

list_documents — List documents

List your documents with pagination.

ParameterRequiredDescription
pageNoPage number (0-based, default: 0)
sizeNoPage size (max 50, default: 20)

Usage Examples

Just ask your AI client in natural language and DraftURL MCP tools will be called automatically.

Create & Share a document

You: "Create an HTML report of this quarter's marketing results and share it on DraftURL"

AI: Writes an HTML report and calls create_document.

Result: https://drafturl.com/xK9mP2nQ — Share this URL with your team.

Update an existing document

You: "Change the title of xK9mP2nQ to '2026 Q1 Marketing Report'"

AI: Calls update_document to update the title.

List your documents

You: "Show me my DraftURL documents"

AI: Calls list_documents and displays titles, URLs, and creation dates.

Create a password-protected document

You: "Upload this proposal to DraftURL with password '1234'"

AI: Calls create_document with password: "1234".

Share a Markdown file

You: "Upload the README.md to DraftURL"

AI: Reads the file and calls create_document with type: "markdown".

Troubleshooting

"Session not found" error

MCP sessions may expire after server updates. In Claude Code, use the /mcp command to restart the drafturl server.

Authentication keeps being requested

Access tokens auto-refresh every hour. If browser cookies were cleared or the server was restarted, re-authentication may be required.

Google login doesn't work

On the MCP login page, click "Continue with Google" to be redirected to the DraftURL login page. After Google login, you'll be automatically returned to the MCP authorization screen.

"DOCUMENT_LIMIT_EXCEEDED" error

Free plan allows up to 30 documents. Delete existing documents and try again.
