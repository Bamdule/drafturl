MCP Connection Guide

DraftURL provides an MCP (Model Context Protocol) server. You can create and manage documents on DraftURL directly from AI clients like Claude Desktop, Claude Code, and Cursor.

MCP Server Info

ItemValue
Server URLhttps://drafturl.com/mcp/transport
ProtocolStreamable HTTP
AuthenticationOAuth2 (PKCE)

Setup by Client

Claude Desktop

Add the following to your claude_desktop_config.json.

{
  "mcpServers": {
    "drafturl": {
      "url": "https://drafturl.com/mcp/transport"
    }
  }
}

Config file location:

  • macOS: ~/Library/Application Support/Claude/claude_desktop_config.json
  • Windows: %APPDATA%\Claude\claude_desktop_config.json

Claude Code

Run the following command in your terminal.

claude mcp add drafturl --transport streamable-http https://drafturl.com/mcp/transport

Cursor

Add the following to .cursor/mcp.json in your project root.

{
  "mcpServers": {
    "drafturl": {
      "url": "https://drafturl.com/mcp/transport"
    }
  }
}

Available Tools

ToolDescriptionAuth
create_documentCreate an HTML or Markdown document and get a shareable URL.Optional
get_documentGet a document's content and metadata by slug.Required
update_documentUpdate an existing document's content, title, or password.Required
delete_documentDelete a document.Required
list_documentsList your documents with pagination.Required

create_document Parameters

ParameterRequiredDescription
contentYesDocument content (HTML or Markdown)
typeYesDocument type: html or markdown
titleNoDocument title (max 200 chars)
passwordNoPassword to protect document (4-100 chars)

Authentication

The get, update, delete, and list tools require login. When you first call a tool that requires authentication, the OAuth2 flow starts automatically.

  1. A DraftURL login page opens in your browser.
  2. Log in and approve access.
  3. Once authenticated, you're returned to the MCP client.

Note: create_document works without login, but guest documents expire after 24 hours.

Usage Examples

Try asking Claude:

  • "Share this markdown document on DraftURL"
  • "Show me my DraftURL documents"
  • "Upload this HTML report to DraftURL and give me the URL"
