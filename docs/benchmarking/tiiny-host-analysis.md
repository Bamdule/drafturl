# Tiiny.host 홈페이지 분석 리포트

> 분석일: 2026-03-21

## 1. 서비스 개요

**"The simplest way to share your work online"** — 정적 웹사이트(HTML/CSS/JS)를 가장 간단하게 호스팅할 수 있는 플랫폼. 드래그 앤 드롭으로 파일을 올리면 즉시 라이브 URL이 생성된다.

- **인프라**: AWS 기반
- **활성 사용자**: 900,000+명
- 계정 가입 없이도 바로 배포 가능

## 2. 핵심 기능

| 기능 | 설명 |
|------|------|
| **드래그 앤 드롭 배포** | ZIP 또는 HTML/CSS/이미지 파일을 끌어다 놓으면 즉시 배포 |
| **커스텀 도메인** | 가이드된 DNS 설정 + 자동 SSL 인증서 |
| **비밀번호 보호** | 클라이언트 프리뷰, 내부 리뷰용 접근 제한 |
| **내장 분석** | 방문자 추적, 경량 애널리틱스 |
| **QR 코드 생성** | 사이트 공유용 QR 자동 생성 |
| **임베드 지원** | 다른 플랫폼에 삽입 가능 |

## 3. 배포 프로세스 (3단계)

```
① 파일 업로드 (드래그 앤 드롭)
     ↓
② 링크명 설정 & 사이트 설정 커스터마이징
     ↓
③ 발행 → 즉시 공유 가능한 URL 생성
```

## 5. 타겟 사용자

- **디자이너/개발자**: 포트폴리오, 프로토타입 공유
- **프리랜서**: 클라이언트 데모/프리뷰
- **비개발자**: 코딩 지식 없이 웹 호스팅
- **마케터**: 랜딩 페이지 빠른 배포
- **학생/교육자**: 프로젝트 공유

## 6. 기술적 특징

- **SPA 아키텍처**: 홈페이지 자체가 JS로 렌더링되는 싱글 페이지 앱
- **마케팅/분석 스택**:
  - Google Tag Manager (GTM-M3CN2V3)
  - Crisp 채팅 (실시간 고객 지원)
  - Facebook Pixel (전환 추적)
  - LinkedIn Pixel (광고 추적)
  - Cello (분석/미터링)
- **정적 호스팅 특성**: 서버 사이드 처리 불필요 → 빠른 로딩, 보안 우수

## 7. 강점 vs 약점

| 강점 | 약점 |
|------|------|
| 극도로 간단한 배포 UX | 무료 플랜 3MB 제한이 매우 작음 |
| 가입 없이 즉시 배포 가능 | 동적 사이트 (서버사이드) 미지원 |
| 비밀번호 보호 기능 | 유료 플랜 가격이 경쟁사 대비 다소 높음 |
| 자동 SSL + 커스텀 도메인 | 수정/업데이트 제한적이라는 리뷰 존재 |
| 90만+ 사용자 신뢰 기반 | |

## 8. 포지셔닝 요약

> **"코딩/서버 지식 없이도 정적 사이트를 30초 만에 배포"** 라는 극단적 단순함에 집중한 서비스.
> Vercel/Netlify 같은 개발자 중심 플랫폼과 달리, **비기술 사용자도 사용할 수 있는 호스팅**을 지향.

### 전략적 포인트

1. **마찰 제거 전략** — 가입, CLI, Git 연동 같은 단계를 모두 생략하고 "파일 드롭 → 즉시 라이브"라는 최단 경로를 제공. 개발자 도구에 익숙하지 않은 사용자를 타겟.
2. **마케팅 추적 집중** — GTM, Facebook/LinkedIn Pixel, Crisp 등 5개 이상의 추적 도구를 사용. 유입 채널별 전환율을 정밀하게 측정하려는 그로스 해킹 전략.
3. **클론 시 참고할 점** — 핵심은 "업로드 → 즉시 미리보기" UX와 비밀번호 보호 기능.
