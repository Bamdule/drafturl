## 요약

- tiiny.host를 주요 경쟁사로 분석하고, CodePen/JSFiddle/GitHub Pages/Claude Artifacts 등과 비교
- 핵심 해자는 "배포 이후 AI 수정 루프"로, 경쟁사가 작성 또는 배포에서 멈추는 것과 차별화
- LLM 제공사의 직접 공유 기능 추가 위협에 대해 멀티 LLM 중립성, 문서 라이프사이클 관리, 전환 비용 구축으로 방어
- LLM 생태계 통합, 붙여넣기 배포, 커뮤니티 주도 성장 등 4가지 실행 전략 제시

## 1. tiiny.host 상세 분석

### 서비스 개요

**"The simplest way to share your work online"** — 정적 웹사이트(HTML/CSS/JS)를 가장 간단하게 호스팅할 수 있는 플랫폼. 드래그 앤 드롭으로 파일을 올리면 즉시 라이브 URL이 생성된다.

- **인프라**: AWS 기반
- **활성 사용자**: 900,000+명
- 계정 가입 없이도 바로 배포 가능

### 핵심 기능

| 기능 | 설명 |
|------|------|
| **드래그 앤 드롭 배포** | ZIP 또는 HTML/CSS/이미지 파일을 끌어다 놓으면 즉시 배포 |
| **커스텀 도메인** | 가이드된 DNS 설정 + 자동 SSL 인증서 |
| **비밀번호 보호** | 클라이언트 프리뷰, 내부 리뷰용 접근 제한 |
| **내장 분석** | 방문자 추적, 경량 애널리틱스 |
| **QR 코드 생성** | 사이트 공유용 QR 자동 생성 |
| **임베드 지원** | 다른 플랫폼에 삽입 가능 |

### 배포 프로세스 (3단계)

```
1. 파일 업로드 (드래그 앤 드롭)
     |
2. 링크명 설정 & 사이트 설정 커스터마이징
     |
3. 발행 -> 즉시 공유 가능한 URL 생성
```

### 가격 정책

| 플랜 | 월 요금 | 연간 환산 | 특징 |
|------|---------|-----------|------|
| **Free** | $0 | - | 1개 사이트, 3MB 제한 |
| **Tiny** | $9/월 | $5/월 (연 $60) | 기본 호스팅 |
| **Solo** (인기) | $18/월 | - | 중간 규모 |
| **Pro** | $38/월 | $31/월 (연 $372) | 고급 기능 |
| **Pro Max** | - | - | 최상위 플랜 |

### 타겟 사용자

- **디자이너/개발자**: 포트폴리오, 프로토타입 공유
- **프리랜서**: 클라이언트 데모/프리뷰
- **비개발자**: 코딩 지식 없이 웹 호스팅
- **마케터**: 랜딩 페이지 빠른 배포
- **학생/교육자**: 프로젝트 공유

### 강점 vs 약점

| 강점 | 약점 |
|------|------|
| 극도로 간단한 배포 UX | 무료 플랜 3MB 제한이 매우 작음 |
| 가입 없이 즉시 배포 가능 | 동적 사이트 (서버사이드) 미지원 |
| 비밀번호 보호 기능 | 유료 플랜 가격이 경쟁사 대비 다소 높음 |
| 자동 SSL + 커스텀 도메인 | 수정/업데이트 제한적이라는 리뷰 존재 |
| 90만+ 사용자 신뢰 기반 | |

### 전략적 포인트

1. **마찰 제거 전략** — 가입, CLI, Git 연동 같은 단계를 모두 생략하고 "파일 드롭 -> 즉시 라이브"라는 최단 경로를 제공. 개발자 도구에 익숙하지 않은 사용자를 타겟.
2. **마케팅 추적 집중** — GTM, Facebook/LinkedIn Pixel, Crisp 등 5개 이상의 추적 도구를 사용. 유입 채널별 전환율을 정밀하게 측정하려는 그로스 해킹 전략.
3. **클론 시 참고할 점** — 핵심은 "업로드 -> 즉시 미리보기" UX와 비밀번호 보호 기능.

### 본 서비스와의 차별점

| 구분 | tiiny.host | 본 서비스 |
|------|-----------|-----------|
| **핵심 가치** | "파일을 URL로 변환" (범용 정적 호스팅) | "LLM이 만든 문서를 즉시 공유하고 계속 수정" |
| **입력 방식** | 드래그 앤 드롭 (파일 업로드) | LLM 출력 붙여넣기 + 파일 업로드 + API 연동 |
| **수정 방식** | 파일 재업로드 (수동) | LLM 프롬프트로 실시간 수정 (AI-native) |
| **타겟 사용자** | 비개발자 범용 | LLM 사용자 (개발자, 기획자, 팀) |
| **콘텐츠 성격** | 정적 사이트 일반 | LLM 생성 문서 특화 (HTML, MD, 발표자료) |

## 2. 경쟁사 비교

| 서비스 | 핵심 가치 | 타겟 사용자 | AI 수정 | 가격 | 본 서비스와의 차이 |
|--------|----------|-----------|---------|------|------------------|
| **tiiny.host** | 극단적 단순함의 정적 호스팅 | 비개발자 범용 | X | $0~$38/월 | 수정이 파일 재업로드 방식. AI 기능 없음 |
| **CodePen** | 프론트엔드 코드 실험/공유 | 프론트엔드 개발자 | X | $0~$12/월 | 코드 에디터 중심. 문서 공유 목적이 아님 |
| **JSFiddle** | 빠른 코드 스니펫 테스트 | 개발자 | X | 무료 | 프로토타이핑 도구. 공유 URL 지원하나 문서 관리 기능 없음 |
| **GitHub Pages** | Git 기반 정적 사이트 호스팅 | 개발자 | X | 무료 | Git 지식 필수. 비개발자 접근성 낮음 |
| **Claude Artifacts** | Claude 대화 중 코드/문서 미리보기 | Claude 사용자 | 내장 | Claude 구독 | 대화 내 임시 렌더링. URL 공유 불가, 독립 호스팅 아님 |
| **Vercel/Netlify** | Git push 기반 빌드/배포 | 개발자 | X | $0~$20/월 | 풀 빌드 파이프라인. 비개발자에게 과도한 복잡도 |

## 3. 핵심 해자(Moat): AI-Native 문서 워크플로우

```
tiiny.host:        파일 업로드 -> URL (끝)
CodePen/JSFiddle:  코드 작성 -> 미리보기 (공유는 부수적)
GitHub Pages:      Git push -> 빌드 -> URL (개발자 전용)
Claude Artifacts:  대화 중 미리보기 (URL 공유 불가)
본 서비스:          입력 -> URL -> AI로 계속 수정 -> 버전 관리 (순환)
```

경쟁사는 "작성" 또는 "배포"에서 끝나지만, 본 서비스는 **배포 이후의 AI 수정 루프**를 핵심 가치로 가져간다.

---

## 4. 방어 전략: LLM 제공사의 직접 공유 기능 추가 시

Claude Artifacts, ChatGPT Canvas 등 LLM 제공사가 직접 "URL 공유" 기능을 추가할 가능성은 가장 큰 위협이다.

**방어 포인트**:

1. **멀티 LLM 중립 플랫폼**: 특정 LLM에 종속되지 않고, 어떤 LLM의 출력이든 하나의 플랫폼에서 관리. LLM 제공사는 자사 출력물만 지원하지만, 본 서비스는 모든 LLM 출력을 통합 관리한다.

2. **문서 라이프사이클 관리**: 단순 공유를 넘어 버전 히스토리, 팀 협업, 분석 대시보드 등 LLM 제공사가 쉽게 구현하지 않을 "문서 관리 플랫폼" 기능을 축적한다.

3. **전환 비용 구축**: 버전 히스토리, 팀 워크스페이스, 커스텀 도메인 연결 등으로 이탈 비용을 높인다.

4. **생태계 통합**: CLI/API, MCP 서버로 개발자 워크플로우에 깊이 통합한다. LLM 제공사의 공유 기능은 자사 UI 내에 한정되지만, 본 서비스는 모든 개발 도구에서 접근 가능하다.

## 5. 경쟁 우위 실행 전략

### 전략 1: LLM 생태계 깊은 통합

- **Claude Code MCP 서버** 제공 -> Claude Code에서 직접 배포 명령
- **ChatGPT Custom Actions** / **Cursor 플러그인** 등 확장
- LLM 도구 사용자들의 자연스러운 워크플로우 안에 진입

### 전략 2: "붙여넣기 배포"로 최소 마찰

- tiiny.host의 강점(극단적 단순함)을 계승
- 차이점: 파일 업로드뿐 아니라 **텍스트 붙여넣기**도 지원 -> LLM 출력을 복사해서 바로 배포
- 가입 없이 임시 URL 즉시 생성 (가입 유도는 만료 전 알림으로)

### 전략 3: 커뮤니티 주도 성장

- AI/LLM 관련 커뮤니티(Twitter/X, Discord, Reddit)에서 유스케이스 공유
- "Claude로 만든 발표자료를 3초 만에 공유" 같은 바이럴 콘텐츠
- 오픈소스 CLI 도구 제공 -> 개발자 커뮤니티 유입

### 전략 4: 전환 비용 구축

- 버전 히스토리가 쌓일수록 이탈 비용 증가
- 팀 워크스페이스로 조직 단위 고착화
- 커스텀 도메인 연결 후 이전 부담
