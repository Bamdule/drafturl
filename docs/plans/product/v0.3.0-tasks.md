# DraftURL — v0.3.0 작업 목록

> 작성일: 2026-03-28
> 상태: 확정
> 이전 버전: v0.2.0 (개발 인프라 안정화 & 사용성 개선)

## 개요

v0.3.0은 사용자 접근성 확대, 공유 기능 강화, 보안 점검에 집중한다.

---

## 작업 목록 (우선순위 순)

### 1. 소셜 로그인 추가

기존 Google/GitHub 외에 네이버, 카카오 OAuth2를 추가한다.

- 네이버 OAuth2 연동 (백엔드 + 프론트엔드)
- 카카오 OAuth2 연동 (백엔드 + 프론트엔드)
- 로그인 페이지 UI에 네이버/카카오 버튼 추가

### 2. 보안 점검

서비스 전반의 보안 취약점을 점검하고 보완한다.

- JWT 토큰 관리 점검 (만료, 갱신, 무효화)
- OAuth2 state 검증 및 CSRF 방어 점검
- XSS 방어 점검 (문서 렌더링 시 스크립트 실행 차단)
- Rate Limiting 도입 (API 엔드포인트별 요청 제한)
- 입력값 검증 강화

### 3. 공유 문서 비밀번호 보호

공유 문서에 비밀번호를 설정하여 접근을 제한할 수 있다.

- 문서 생성/수정 시 비밀번호 설정 옵션 추가
- 비밀번호가 설정된 문서 접근 시 입력 화면 표시
- 비밀번호 검증 API
- 비밀번호 해싱 저장 (bcrypt)

### 4. QR 코드 접근

공유 URL을 QR 코드로 생성하여 모바일에서 쉽게 접근할 수 있다.

- 문서 공유 시 QR 코드 자동 생성
- QR 코드 다운로드(PNG) 기능
- 공유 모달에 QR 코드 탭 추가

### 5. 백엔드 단위 테스트 보강

핵심 비즈니스 로직에 대한 회귀 테스트를 추가하여 코드 안전망을 구축한다.

- [x] UseCase 단위 테스트 6개 (Create, View, Update, Delete, GetList, GetForEdit)
- [x] 인프라 단위 테스트 2개 (SlugGenerator, JwtProvider)
- [x] 기존 RestDocs 테스트 수정 (UseCase 패턴 반영)
- 총 96개 테스트 통과

### 6. 다중 문서 공유

여러 문서를 하나의 URL로 묶어 공유할 수 있다.

- 문서 컬렉션(묶음) 생성 API
- 컬렉션 공유 URL 발급
- 컬렉션 뷰어 페이지 (문서 목록 + 개별 열람)
- 대시보드에서 문서 선택 → 묶음 공유 UI

### 7. SEO 강화

검색 엔진 노출을 개선하여 국내외 사용자의 자연 유입을 늘린다.

#### 7-1. 다국어 라우팅 (i18n)
- `/ko`, `/en` 경로 분리 (Next.js middleware 기반)
- 홈페이지 영문 UI 번역
- `<html lang>` 동적 전환
- hreflang 태그가 실제 다른 언어 URL을 가리키도록 수정

#### 7-2. 구조화 데이터 보완
- BreadcrumbList JSON-LD 추가 (홈 > 문서)
- 문서 페이지 keywords 동적 생성

#### 7-3. 검색엔진 등록 (운영)
- Google Search Console 등록 + sitemap 제출
- Bing Webmaster Tools 등록
- Rich Results Test 검증

#### 7-4. 소셜 채널 연결 (운영)
- OG 이미지 실제 렌더링 검증 (Facebook Sharing Debugger, X Card Validator)
- 공식 SNS 계정 생성 후 twitter:site 메타태그 연결
