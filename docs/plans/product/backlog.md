# DraftURL — 백로그

> 최종 수정일: 2026-03-27

버전 범위에 포함되지 않은 작업 후보 목록. 우선순위 확정 시 해당 버전 작업 문서로 이동한다.

---

## 기능

| 항목 | 설명 | 비고 |
|------|------|------|
| MCP 서버 | LLM에서 직접 문서 생성/조회/수정/삭제 → URL 발급 | v0.3.0 후보 |
| 소셜 로그인 추가 | 네이버, 카카오 OAuth2 | v0.3.0 후보 |
| AI 수정 기능 | Claude API 연동, 문서 내용 AI 수정 | Phase 2 핵심 |
| 버전 히스토리 | 문서 수정 이력 관리 | AI 수정과 함께 도입 |
| 비밀번호 보호 | 공유 문서에 비밀번호 설정 | |
| 커스텀 도메인 | 사용자 도메인으로 문서 서빙 | 인프라 복잡도 높음 |
