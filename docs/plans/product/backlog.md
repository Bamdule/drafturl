## Backlog Pool (전체 후보)

### 기능

| 항목 | 설명 |
|------|------|
| **버전 히스토리** | 문서 수정 이력 관리. diff 뷰, 롤백. 버전이 쌓일수록 전환 비용 구축 |
| **AI 수정 기능** | 웹 UI에서 프롬프트로 문서 수정. LLM API 직접 호출 (Claude/OpenAI/Gemini). 비용 추정: 1회 ~₩20. 도입 시점: 수익 발생 후 |
| **커스텀 도메인** | 사용자 도메인으로 문서 서빙. 인프라 복잡도 높음 |
| **이메일 알림 (Resend)** | 문의 접수 시 관리자 이메일 알림, 시스템 발송 (noreply@). Resend 연동 필요 |
| **탈퇴 로그** | withdrawal_logs 테이블 추가. 감사/통계용 최소 정보 기록 (DB 마이그레이션 필요) |
| **팀/조직 접근 제어** | 팀 워크스페이스, 조직 단위 문서 공유 제한. B2B 피벗 시 |
| **열람 추적** | 공유 문서를 누가, 언제 열었는지 추적. B2B 차별점 |
| **Slack/Teams 연동** | 문서 생성/수정 알림, 슬래시 커맨드 문서 생성. B2B 차별점 |
| **데이터 연동 퍼블리싱** | CSV → 차트/테이블 자동 생성 → URL 배포. 피벗 방향 1 |
| **마이크로 웹사이트 빌더** | 테마 + LLM 생성 → 포트폴리오/이력서/이벤트 페이지. 피벗 방향 2 |
