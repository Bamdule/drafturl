# DraftURL — 백로그

> 최종 수정일: 2026-03-29

버전 범위에 포함되지 않은 작업 후보 목록. 우선순위 확정 시 해당 버전 작업 문서로 이동한다.

---

## 전략적 우선순위

핵심 방향: **멀티 LLM 중립 플랫폼 + 워크플로우 통합(MCP)** — 어떤 AI 도구에서든 DraftURL을 거쳐야 URL이 나오는 구조.

| 순서 | 항목 | 이유 |
|------|------|------|
| 1 | MCP 서버 | 비용 0 (사용자 AI 활용), 핵심 차별점, 구현 단순 |
| 2 | 버전 히스토리 | 전환 비용 구축, MCP update 시 자동 버전 생성 |
| 3 | AI 수정 기능 | MCP 없는 일반 사용자용, 수익 확보 후 도입 |
| 4 | 팀/조직 기능 | B2B 확장, 사용자 확보 후 |

> 다중 문서 공유, Rate Limiting은 v0.3.0 작업 범위에 포함되어 있음.

---

## 기능

### MCP 서버 (우선순위 1)

LLM 도구(Claude Code, Cursor, ChatGPT Desktop, Gemini CLI 등)에서 직접 문서를 조작하는 MCP 서버.

- **도구 목록**: create_document, get_document, update_document, delete_document, list_documents
- **비용 구조**: DraftURL 서버는 저장소 역할만. AI 비용은 사용자 부담 (자기 AI 키 사용)
- **전략적 의미**: 멀티 LLM 중립 플랫폼의 핵심. 어떤 AI 도구에서든 DraftURL로 배포 가능
- **경쟁 우위**: Gamma/Claude Artifacts/ChatGPT Canvas는 자사 생태계에 갇혀 있으나, MCP는 모든 클라이언트에서 연결 가능

### 버전 히스토리 (우선순위 2)

문서 수정 이력 관리. MCP update_document 호출 시 자동으로 이전 버전 저장.

- 버전 비교(diff) 뷰
- 특정 버전으로 롤백
- 버전이 쌓일수록 이탈 비용 증가 → 전환 비용 구축

### AI 수정 기능 (우선순위 3)

DraftURL 웹 UI 내에서 프롬프트로 문서를 수정하는 기능. MCP 없는 일반 사용자 대상.

- DraftURL 백엔드에서 LLM API 직접 호출 (Claude/OpenAI/Gemini 멀티 모델 지원)
- **비용**: DraftURL이 API 비용 부담 → Rate Limiting + 월 예산 상한 필수
- **비용 추정** (Haiku 기준): 1회 수정 ~₩20, 무료 5회/일, 유료 50회/일
- **도입 시점**: MCP로 사용자 확보 + 수익 발생 후

### 커스텀 도메인

사용자 도메인으로 문서 서빙. 인프라 복잡도 높음. 연결 후 이전 부담 → 전환 비용 구축.

### 기타 기능 후보

| 항목 | 설명 | 비고 |
|------|------|------|
| 데이터 연동 퍼블리싱 | CSV 업로드 → 차트/테이블 자동 생성 → URL 배포 | 피벗 방향 1 |
| 마이크로 웹사이트 빌더 | 테마 선택 + LLM 생성 → 포트폴리오/이력서/이벤트 페이지 | 피벗 방향 2 |
| 팀/조직 접근 제어 | 팀 워크스페이스, 조직 단위 문서 공유 제한 | 피벗 방향 3 (B2B) |
| 열람 추적 | 공유 문서를 누가, 언제 열었는지 추적 | B2B 차별점 |
| Slack/Teams 연동 | 문서 생성/수정 시 알림, 슬래시 커맨드로 문서 생성 | B2B 차별점 |
