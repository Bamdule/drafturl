## 개요

v0.2.0은 개발 인프라 안정화, 사용성 개선, 모바일 대응에 집중한다.

## 작업 목록 (우선순위 순)

### 1. 개발서버 CI/CD 구축

갤럭시 북 3 개발서버에 자동 배포 파이프라인을 구축한다.

- GitHub Actions + Self-hosted Runner 방식 검토
- main 브랜치 병합 시 자동 빌드 및 배포
- 헬스체크 API 추가 (`/api/v1/health`)
- 배포 후 헬스체크 자동 확인

> 참고: [개발서버 구축 계획](../infra/dev-server-plan.md), [릴리즈 관리 가이드](../infra/release-guide.md)

### 2. 사용성 개선

| # | 항목 | 설명 |
|---|------|------|
| 2-1 | 자동 타이핑 데모 제한 | 메인 페이지 데모 데이터는 미리보기만 허용, 공유 버튼 비활성화 |
| 2-2 | 문서 삭제 UI 개선 | 삭제 모달의 버튼 색상 개선 (빨간/하양 혼란 해소) |
| 2-3 | 아이콘 개선 | 기본 아이콘 → 서비스 톤에 맞는 커스텀 아이콘으로 교체 |
| 2-4 | 서비스 소개 및 사용 가이드 | DraftURL 소개, 사용법, 활용 팁을 사이트 내에 명시 |
| 2-5 | 문서 기본 제목 변경 | "제목 없음" → `YYYY-MM-DD HH:mm 문서` 형식으로 기본 생성 |
| 2-6 | 에러 페이지 개선 | 만료된 문서 접근 시 전용 안내 페이지 제공 |
