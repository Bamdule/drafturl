## 비로그인 문서 생성

### TC-CREATE-01: 비로그인 HTML 문서 생성 + 공유 URL 발급

**사전 조건**: 로그아웃 상태, 홈 페이지(`/`)
**테스트 단계**:
1. HTML 탭 선택 확인
2. 에디터에 HTML 내용 입력 (예: `<h1>Hello</h1><p>World</p>`)
3. "공유하기" 버튼 클릭
**기대 결과**:
- 공유 결과 모달 표시
- 공유 URL 표시 (예: `https://drafturl.com/abcd1234`)
- "비로그인 문서는 24시간 후 만료됩니다" 안내 문구 표시
- 공유 URL로 접근 시 HTML 문서 정상 렌더링
**자동화**: 가능

### TC-CREATE-11: 파일 로드 시 태그/비밀번호 옵션 섹션 표시

**사전 조건**: 로그인 상태, 홈 페이지(`/`)
**테스트 단계**:
1. .html 또는 .md 파일을 에디터에 로드 (드롭 또는 파일 선택)
2. 파일명/크기 표시 아래 영역 확인
**기대 결과**:
- "태그" 레이블과 기존 태그 목록이 표시됨
- "비밀번호 설정" 토글 버튼 표시됨
- 공유하기 버튼 위에 옵션 섹션이 위치함
**자동화**: 가능

### TC-CREATE-12: 공유 전 기존 태그 선택 후 공유

**사전 조건**: 로그인 상태, 기존 태그 1개 이상 존재, 파일 로드된 상태
**테스트 단계**:
1. 태그 옵션 섹션에서 기존 태그 클릭 (선택됨 표시 확인)
2. "공유하기" 클릭
3. 대시보드에서 해당 문서 확인
**기대 결과**:
- 선택된 태그가 chip 형태로 표시됨 (선택 전/후 스타일 구분)
- 공유 후 대시보드 문서 카드에 태그 배지 표시됨
**자동화**: 가능

### TC-CREATE-13: 공유 전 새 태그 생성 (deferred — 공유 시점에 DB 저장)

**사전 조건**: 로그인 상태, 파일 로드된 상태
**테스트 단계**:
1. 태그 입력창에 새 태그명 입력 (예: "신규태그")
2. Enter 키 또는 "만들기" 클릭
3. chip이 추가되는지 확인 (API 호출 없음 확인 — DevTools Network 탭)
4. "공유하기" 클릭
5. 대시보드 확인
**기대 결과**:
- 2단계에서 API 호출 없이 로컬 chip만 추가됨 (orphan 태그 미생성)
- 공유 후 태그가 DB에 생성되고 문서에 연결됨
- 대시보드 문서 카드에 해당 태그 표시됨
**자동화**: 가능

### TC-CREATE-14: 공유 전 비밀번호 설정

**사전 조건**: 로그인 상태, 파일 로드된 상태

- 정확한 비밀번호 입력 시 문서 열람 가능
**자동화**: 가능

## 한글 IME 태그 입력

### TC-CREATE-16: 한글 태그 입력 후 Enter — 중복 생성 방지

**사전 조건**: 로그인 상태, 파일 로드된 상태 (태그 옵션 섹션 표시됨)
**테스트 단계**:
1. 태그 입력창에 한글 단어 입력 (예: "도시")
2. Enter 키 누르기
3. 추가된 chip 개수 확인
**기대 결과**: chip이 정확히 1개만 추가됨 ("도시" 1개). IME 조합 중 Enter로 "시"가 별도 추가되는 현상 없음
**회귀 이슈**: 한글 IME 이중 발화 버그 — `isComposing: true`인 keydown 이벤트를 무시하도록 수정
**자동화**: 부분 가능 (실제 IME 시뮬레이션 필요)
