## 비로그인 문서 생성

### TC-CREATE-01: 비로그인 HTML 문서 생성 + 공유 URL 발급

**사전 조건**: 로그아웃 상태, 홈 페이지(`/`)
**테스트 단계**:
1. HTML 탭 선택 확인
2. 에디터에 HTML 내용 입력 (예: `<h1>Hello</h1><p>World</p>`)
3. "공유하기" 버튼 클릭
**기대 결과**:
- 공유 결과 모달 표시
- 공유 URL 표시 (예: `https://drafturl.com/abcd1234`)
- "비로그인 문서는 24시간 후 만료됩니다" 안내 문구 표시
- 공유 URL로 접근 시 HTML 문서 정상 렌더링
**자동화**: 가능

### TC-CREATE-02: 비로그인 Markdown 문서 생성 + 공유

**사전 조건**: 로그아웃 상태, 홈 페이지(`/`)
**테스트 단계**:
1. Markdown 탭 클릭
2. 에디터에 Markdown 내용 입력 (예: `# 제목\n\n본문 내용`)
3. "공유하기" 버튼 클릭
**기대 결과**:
- 공유 결과 모달 표시
- 공유 URL 발급
- 공유 URL로 접근 시 Markdown이 HTML로 변환되어 렌더링
**자동화**: 가능

## 로그인 문서 생성

### TC-CREATE-03: 로그인 상태 문서 생성 (영구 보관)

**사전 조건**: 로그인 상태, 홈 페이지(`/`)
**테스트 단계**:
1. 에디터에 내용 입력
2. (선택) 제목 입력
3. "공유하기" 버튼 클릭
**기대 결과**:
- 공유 결과 모달 표시
- 만료 안내 문구 없음 (영구 보관)
- 대시보드에서 해당 문서 확인 가능
- 문서의 `expiresAt`이 null
**자동화**: 가능

## 유효성 검증

### TC-CREATE-04: 5MB 초과 문서 거부

**사전 조건**: 홈 페이지(`/`)

1. 에디터에 5MB를 초과하는 내용 입력 (또는 5MB 초과 파일을 드롭 후 공유)

### TC-CREATE-05: 빈 내용 공유 시도

**사전 조건**: 홈 페이지(`/`), 에디터 내용 비어 있음

## 공유 후 비밀번호 설정 (로그인 사용자)

### TC-CREATE-11: 공유 후 비밀번호 설정 (로그인)

**사전 조건**: 로그인 상태, 문서 공유 성공 후 결과 모달 표시
**테스트 단계**:
1. 모달에서 "비밀번호 설정" 링크 확인
2. 클릭하여 비밀번호 입력 필드 표시
3. 비밀번호 입력 (4자 이상)
4. "설정" 버튼 클릭
**기대 결과**:
- "비밀번호가 설정되었습니다" 메시지 표시
- 공유 URL 접근 시 비밀번호 입력 요구
- 브라우저 비밀번호 저장 팝업이 뜨지 않음
**자동화**: 가능

### TC-CREATE-12: 비밀번호 4자 미만 입력 시 거부

**사전 조건**: 로그인 상태, 공유 결과 모달에서 비밀번호 입력 필드 표시
**테스트 단계**:
1. 비밀번호에 3자 이하 입력 (예: "abc")
2. "설정" 버튼 클릭
**기대 결과**: "비밀번호는 4자 이상이어야 합니다" 에러 메시지 표시
**자동화**: 가능

### TC-CREATE-13: 비로그인 상태에서 비밀번호 설정 UI 미노출

**사전 조건**: 로그아웃 상태, 문서 공유 성공 후 결과 모달 표시
