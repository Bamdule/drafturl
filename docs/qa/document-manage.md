## 문서 목록

### TC-MANAGE-01: 대시보드 문서 목록 표시

**사전 조건**: 로그인 상태, 1개 이상 문서 생성 완료
**테스트 단계**:
1. `/dashboard` 접근
2. 문서 목록 확인
**기대 결과**:
- 문서 목록이 카드 형태로 표시
- 기본 정렬: 등록일 내림차순 (최신 문서가 상단)
- 각 카드에 제목, 문서 타입 배지(HTML/MD), 파일 크기, 생성일시 표시
- 미리보기 텍스트(preview)가 있으면 카드 내 표시 (최대 1줄 truncate)
- 태그가 있으면 카드 내 배지로 표시
- 자동 생성된 제목(날짜형식)은 italic + muted 스타일로 표시
**자동화**: 가능

### TC-MANAGE-02: 통계 카드 (문서 수, 용량, 플랜)

**사전 조건**: 로그인 상태, `/dashboard` 페이지

### TC-MANAGE-15: 한글 제목 검색 (NFC 정규화)

**사전 조건**: macOS에서 파일명이 한글인 파일을 드래그앤드롭으로 공유한 문서 존재
**테스트 단계**:
1. 검색창에 해당 한글 제목 입력
2. 결과 확인
**기대 결과**: 문서가 검색 결과에 표시됨 (NFD/NFC 불일치로 검색 실패하지 않음)
**회귀 이슈**: macOS HFS+ NFD 파일명과 NFC 검색 입력 간 LIKE 매칭 실패 → Java `Normalizer.normalize(NFC)` + V9 마이그레이션으로 수정
**자동화**: 부분 가능 (NFD 파일명 생성 필요)

## 문서 미리보기

### TC-MANAGE-21: 새 문서 미리보기 텍스트 자동 생성

**사전 조건**: 로그인 상태

## 태그 관리 (TagPicker)

### TC-MANAGE-23: TagPicker — 기존 태그를 문서에 연결

**사전 조건**: 로그인 상태, 기존 태그 존재, 대시보드 문서 카드
**테스트 단계**:
1. 문서 카드 hover → `+` 태그 추가 버튼 표시 확인
2. `+` 버튼 클릭 → TagPicker 드롭다운 열림
3. 기존 태그 클릭
4. 드롭다운 닫기 후 카드 확인
**기대 결과**: 선택된 태그가 카드에 배지로 표시됨, API `POST /tags/{id}/documents/{slug}` 호출됨
**자동화**: 가능

### TC-MANAGE-24: TagPicker — 새 태그 생성 및 연결

**사전 조건**: 로그인 상태, TagPicker 열린 상태
**테스트 단계**:
1. 새 태그 입력창에 태그명 입력
2. Enter 또는 "만들기" 버튼 클릭
**기대 결과**: 태그가 DB에 생성되고 문서에 즉시 연결됨, 카드에 배지 표시됨
**자동화**: 가능

### TC-MANAGE-25: TagPicker — 태그 연결 해제

**사전 조건**: 로그인 상태, 태그가 연결된 문서 존재
**테스트 단계**:
1. TagPicker 열기
2. 체크표시가 있는 태그(이미 연결됨) 클릭
**기대 결과**: 태그가 문서에서 해제됨, 카드에서 배지 사라짐
**자동화**: 가능

## 태그 생명주기

### TC-MANAGE-26: 마지막 문서 연결 해제 시 태그 자동 삭제

**사전 조건**: 특정 태그가 딱 1개 문서에만 연결된 상태
**테스트 단계**:
1. TagPicker에서 해당 태그 연결 해제
2. 태그 필터 목록 확인
3. (선택) DB에서 태그 존재 여부 확인
**기대 결과**: 태그가 필터 목록에서 사라짐. 연결된 문서가 0개이면 태그 자동 삭제됨
**자동화**: 가능

### TC-MANAGE-27: 문서 삭제 시 단독 태그 자동 삭제

**사전 조건**: 특정 태그가 딱 1개 문서에만 연결된 상태
**테스트 단계**:
1. 해당 문서 삭제 (확인 다이얼로그에서 확인)
2. 태그 필터 목록 확인
**기대 결과**: 삭제된 문서의 단독 태그도 함께 자동 삭제됨. 다른 문서에도 연결된 태그는 유지됨
**자동화**: 가능
