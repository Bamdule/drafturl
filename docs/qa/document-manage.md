# 문서 관리 QA

> 트리거: `dashboard/`, `DocumentCard`, `DocumentList`, `StorageUsageBar`

---

## 문서 목록

### TC-MANAGE-01: 대시보드 문서 목록 표시

**사전 조건**: 로그인 상태, 1개 이상 문서 생성 완료
**테스트 단계**:
1. `/dashboard` 접근
2. 문서 목록 확인
**기대 결과**:
- 문서 목록이 카드 형태로 표시
- 등록일 내림차순 정렬 (최신 문서가 상단)
- 각 카드에 제목, 문서 타입 배지(HTML/MD), 파일 크기, 생성일시 표시
**자동화**: 가능

### TC-MANAGE-02: 통계 카드 (문서 수, 용량, 플랜)

**사전 조건**: 로그인 상태, `/dashboard` 페이지
**테스트 단계**:
1. 상단 통계 영역 확인
**기대 결과**:
- 문서 수 표시
- 사용 용량 / 최대 용량 표시
- 사용량 프로그레스 바 (StorageUsageBar) 정상 렌더링
**자동화**: 가능

## 문서 제목 수정

### TC-MANAGE-03: 문서 제목 인라인 수정 (Enter 저장)

**사전 조건**: 로그인 상태, `/dashboard` 페이지, 문서 1개 이상
**테스트 단계**:
1. 문서 카드의 제목 텍스트 클릭
2. 인라인 입력창 표시 확인
3. 새 제목 입력
4. Enter 키 누르기
**기대 결과**: 제목이 새 값으로 갱신, 입력창 닫힘, 목록 새로고침
**자동화**: 가능

### TC-MANAGE-04: 문서 제목 인라인 수정 (Escape 취소)

**사전 조건**: 로그인 상태, 문서 카드의 제목 클릭하여 편집 모드
**테스트 단계**:
1. 제목 텍스트 클릭하여 편집 모드 진입
2. 새 제목 입력
3. Escape 키 누르기
**기대 결과**: 원래 제목으로 복원, 입력창 닫힘, API 호출 없음
**자동화**: 가능

## 문서 삭제

### TC-MANAGE-05: 문서 삭제 (확인 다이얼로그)

**사전 조건**: 로그인 상태, `/dashboard` 페이지, 문서 1개 이상
**테스트 단계**:
1. 문서 카드의 "삭제" 버튼 클릭
2. 삭제 확인 다이얼로그 표시 확인
3. "삭제" 버튼 클릭
**기대 결과**: 문서가 soft delete 처리, 목록에서 해당 문서 사라짐
**자동화**: 가능

### TC-MANAGE-06: 문서 삭제 후 목록 갱신

**사전 조건**: TC-MANAGE-05 수행 직후
**테스트 단계**:
1. 문서 목록 확인
2. 브라우저 새로고침
**기대 결과**: 삭제된 문서가 목록에 표시되지 않음, 통계 카드의 문서 수/용량 갱신
**자동화**: 가능

## 네비게이션

### TC-MANAGE-07: 행 클릭 - 새 탭에서 미리보기

**사전 조건**: 로그인 상태, `/dashboard` 페이지, 문서 1개 이상
**테스트 단계**:
1. 문서 카드의 빈 영역(제목/버튼 외) 클릭
**기대 결과**: 새 탭에서 `/{slug}` 페이지 열림, 문서 정상 렌더링
**자동화**: 부분 가능

### TC-MANAGE-08: URL 복사 버튼

**사전 조건**: 로그인 상태, `/dashboard` 페이지
**테스트 단계**:
1. 문서 카드의 "복사" 버튼 클릭
2. 텍스트 에디터에 붙여넣기
**기대 결과**: "복사됨" 피드백 표시 (2초 후 원래 상태 복원), 클립보드에 문서 URL 복사됨
**자동화**: 부분 가능

**사전 조건**: 비로그인으로 생성한 문서가 존재 (expiresAt 값 있음), 해당 문서가 로그인 계정에 연결된 경우 또는 비로그인 문서 확인

**기대 결과**: 문서 카드에 "N시간 N분 남음" 형태의 만료 시간 배지 표시 (주황색)
**자동화**: 가능

## 페이지네이션
