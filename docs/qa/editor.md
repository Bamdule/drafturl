## 에디터 기본 동작

### TC-EDIT-01: Monaco 에디터 입력 + 실시간 미리보기

**사전 조건**: 홈 페이지(`/`), 데스크탑 브라우저
**테스트 단계**:
1. 에디터(좌측)에 HTML 입력 (예: `<h1>Hello</h1>`)
2. 미리보기(우측) 확인
3. 에디터 내용 수정 (예: `<h1>World</h1>`)
4. 미리보기 갱신 확인
**기대 결과**: 에디터 입력 후 300ms debounce 이후 미리보기 자동 갱신, HTML이 iframe srcdoc으로 렌더링
**자동화**: 가능

### TC-EDIT-02: 모바일 textarea 폴백

**사전 조건**: 모바일 브라우저 또는 DevTools에서 모바일 뷰포트 시뮬레이션
**테스트 단계**:
1. 홈 페이지 접근
2. 에디터 영역 확인
**기대 결과**: Monaco Editor 대신 일반 textarea가 표시됨 (모바일 환경에서 Monaco 로드 실패 시 폴백)
**자동화**: 부분 가능

### TC-EDIT-03: HTML/Markdown 탭 전환

**사전 조건**: 홈 페이지(`/`)
**테스트 단계**:
1. HTML 탭 선택 확인

## 파일 드래그앤드롭

### TC-EDIT-04: 파일 드래그앤드롭 (정상)

**사전 조건**: 홈 페이지(`/`), .html 또는 .md 파일 준비
**테스트 단계**:
1. 파일 탐색기에서 .html 파일을 브라우저 페이지 위로 드래그
2. 드래그 오버레이 표시 확인 ("여기에 파일을 놓으세요")
3. 파일 드롭
**기대 결과**:
- 드래그 오버레이가 풀스크린으로 표시 (반투명 배경 + 안내 문구)
- 파일 드롭 후 에디터에 파일 내용 채워짐
- 문서 타입이 파일 확장자에 맞게 자동 전환 (.html -> HTML, .md -> Markdown)
- 성공 토스트 표시 ("파일이름.html 파일을 불러왔습니다.")
**자동화**: 부분 가능

### TC-EDIT-05: 지원하지 않는 파일 형식 드롭

**사전 조건**: 홈 페이지(`/`), .txt 또는 .pdf 파일 준비
**테스트 단계**:
1. 지원하지 않는 확장자 파일을 페이지에 드롭 (예: .txt, .pdf, .jpg)
**기대 결과**: 에러 토스트 표시 ("지원하지 않는 파일 형식입니다. (.html, .htm, .md, .markdown)"), 에디터 내용 변경 없음
**자동화**: 가능

### TC-EDIT-06: 5MB 초과 파일 드롭

**사전 조건**: 홈 페이지(`/`), 5MB 초과 .html 파일 준비
**테스트 단계**:
1. 5MB를 초과하는 .html 파일을 페이지에 드롭
**기대 결과**: 에러 토스트 표시 ("파일 크기가 5MB를 초과합니다."), 에디터 내용 변경 없음
**자동화**: 가능

## 타이핑 애니메이션

### TC-EDIT-07: 타이핑 애니메이션 (첫 진입)

**사전 조건**: 브라우저 쿠키/스토리지 초기화, 홈 페이지 접근
**테스트 단계**:
1. 홈 페이지(`/`) 최초 접근
**기대 결과**:
- 타이핑 오버레이 표시 (왼쪽: 코드 타이핑, 오른쪽: 실시간 미리보기)
- 샘플 코드가 글자 단위로 타이핑되는 애니메이션
- "타이핑 중..." 표시
**자동화**: 부분 가능

### TC-EDIT-08: 타이핑 중 클릭 - 빈 에디터

**사전 조건**: 타이핑 애니메이션 진행 중
**테스트 단계**:
1. 타이핑 오버레이 아무 곳이나 클릭
**기대 결과**: 애니메이션 즉시 중단, 에디터 내용 비어 있음 (데모 내용 제거), 빈 에디터에서 직접 입력 가능
**자동화**: 가능

### TC-EDIT-09: 타이핑 중 파일 드롭

**사전 조건**: 타이핑 애니메이션 진행 중, .html 파일 준비
**테스트 단계**:
1. 메인 페이지 진입 → 타이핑 애니메이션이 진행되는 동안
2. .html 파일을 페이지 아무 곳에 드래그
3. 전체 화면 드롭 오버레이("여기에 파일을 놓으세요")가 표시되는지 확인
4. 파일을 드롭
**기대 결과**:
- 타이핑 애니메이션이 즉시 중단됨
- 드롭된 파일 내용이 에디터에 표시됨 (샘플 내용이 아닌 파일 내용)
- 미리보기에 파일 HTML이 렌더링됨
- 타이핑 애니메이션이 파일 내용을 덮어쓰지 않음
**회귀 이슈**: 오버레이가 드래그 이벤트를 가로채서 FileDropZone까지 도달하지 못하는 문제가 있었음. 오버레이 클릭 레이어에서 드래그 이벤트를 처리하지 않도록 수정하여 해결.
**자동화**: 부분 가능 (Playwright에서 실제 파일 드래그 시뮬레이션 제한적)

### TC-EDIT-10: 탭 전환 시 타이핑 애니메이션

**사전 조건**: 홈 페이지에서 타이핑 애니메이션 완료 또는 클릭으로 해제
**테스트 단계**:
1. HTML 탭에서 내용 입력
2. Markdown 탭으로 전환
**기대 결과**: 탭 전환 시 해당 타입의 샘플 코드로 타이핑 애니메이션 재시작 (구현에 따라 다를 수 있음)
**자동화**: 부분 가능

### TC-EDIT-12: 페이지 전체 영역 드래그앤드롭

**사전 조건**: 홈 페이지(`/`), .md 파일 준비
