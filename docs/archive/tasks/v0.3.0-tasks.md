## 개요

v0.3.0은 사용자 접근성 확대, 공유 기능 강화, 보안 점검에 집중한다.

---

## 작업 목록 (우선순위 순)

### 1. 소셜 로그인 추가

기존 Google/GitHub 외에 네이버, 카카오 OAuth2를 추가한다.

- [x] 네이버 OAuth2 연동 (백엔드 + 프론트엔드)
- [x] 카카오 OAuth2 연동 (백엔드 + 프론트엔드)
- [x] 로그인 페이지 UI에 네이버/카카오 버튼 추가

### 2. 보안 점검

서비스 전반의 보안 취약점을 점검하고 보완한다.

- [x] JWT 토큰 관리 점검 (만료, 갱신, 무효화)
- [x] OAuth2 state 검증 및 CSRF 방어 점검
- [x] XSS 방어 점검 (문서 렌더링 시 스크립트 실행 차단)
- [x] 입력값 검증 강화
- [x] HTML Sanitizer 피싱 방지 강화 (form/input/password 태그 제거)
- [x] 문서 생성(CREATE) 경로에 sanitizer 적용 (기존 UPDATE만 적용)
- [ ] Rate Limiting 도입 (API 엔드포인트별 요청 제한) → v0.4.0 이관

### 3. 공유 문서 비밀번호 보호

공유 문서에 비밀번호를 설정하여 접근을 제한할 수 있다.

- [x] 문서 생성/수정 시 비밀번호 설정 옵션 추가
- [x] 비밀번호가 설정된 문서 접근 시 입력 화면 표시
- [x] 비밀번호 검증 API
- [x] 비밀번호 해싱 저장 (bcrypt)

### 4. MCP 서버 + OAuth2 인증

Claude Desktop 등 AI 클라이언트에서 문서를 관리할 수 있도록 MCP 서버를 구현한다.

- [x] MCP 서버 엔드포인트 구현 (CRUD)
- [x] OAuth2 인증 흐름 (Authorization Code + PKCE)
- [x] 프론트엔드 OAuth2 프록시

### 5. 백엔드 단위 테스트 보강

핵심 비즈니스 로직에 대한 회귀 테스트를 추가하여 코드 안전망을 구축한다.

- [x] UseCase 단위 테스트 6개 (Create, View, Update, Delete, GetList, GetForEdit)
- [x] 인프라 단위 테스트 2개 (SlugGenerator, JwtProvider)
- [x] 기존 RestDocs 테스트 수정 (UseCase 패턴 반영)
- [x] Sanitizer 피싱 방지 테스트 5개 추가

### 6. SEO 강화

검색 엔진 노출을 개선하여 국내외 사용자의 자연 유입을 늘린다.

- [x] 다국어 라우팅 (i18n) — `/ko`, `/en` 경로 분리
- [x] Google Search Console 등록 + sitemap 제출
- [x] Google Search Console 소유권 확인 메타태그 추가

### 7. 모니터링

- [x] Umami 트래킹 스크립트 적용
- [x] Umami 커스텀 이벤트 추적
- [x] Uptime Kuma 모니터링 구성

### 8. UI/UX 개선

- [x] 전체 UI/UX 개선 — 로그인/회원가입/홈/404/대시보드
