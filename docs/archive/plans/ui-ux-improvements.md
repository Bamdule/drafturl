# UI/UX 개선 계획

> 작성일: 2026-03-29
> 분석 범위: 전체 프론트엔드 페이지 (데스크톱 + 모바일)

---

## 분석 결과

### 1. 회원가입 페이지 (/auth/signup)

| 문제 | 설명 |
|------|------|
| 로그인 페이지와 디자인 불일치 | 로그인은 카드 컨테이너 적용 완료, 회원가입은 이전 스타일 (배경에 나열) |
| 로고/제목 과대 | 큰 D 아이콘(64px) + "DraftURL 회원가입" - 로그인의 간결한 스타일과 불일치 |
| 입력 필드 배경 | bg-bg-secondary로 배경과 구분 안 됨 |
| 푸터 스타일 불일치 | 로그인과 다른 푸터 구조 |

**작업**: 로그인 페이지와 동일한 카드 스타일 적용

### 2. 홈페이지 (/)

| 문제 | 설명 |
|------|------|
| 푸터 없음 | 서비스 이용약관, 개인정보 처리방침 링크가 없음 |
| 하단 섹션 불필요하게 김 | Feature 카드 4개 + Step 카드 3개가 에디터 아래에 나열되어 페이지가 과도하게 길음 |

**작업**: 간단한 푸터 추가, 하단 섹션 간결화

### 3. 404 페이지

| 문제 | 설명 |
|------|------|
| 헤더 없음 | 네비게이션이 없어서 사이트 내 이동이 어려움 |
| 브랜딩 부재 | DraftURL 로고나 색상이 없음 |

**작업**: Header 컴포넌트 추가, 브랜딩 적용

### 4. 모바일 공통

| 문제 | 설명 |
|------|------|
| 회원가입 모바일 스크롤 | 4개 필드 + 큰 로고로 인해 스크롤이 과도함 |

**작업**: 회원가입 카드화로 자동 해결
